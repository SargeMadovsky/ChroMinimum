# Подготовка alpha.8 — Windows x64

Актуальный локальный комплект от2026-11-01: [новые заметки и результаты](RELEASE_ALPHA8_20261101.md),
[точные артефакты](reports/downloads-branding-20261101/summary.json). Ниже сохранена история
октябрьских кандидатов; их SHA/установщики не являются новым комплектом.

## Установщик от 2026-10-23

Статус распространения уточнён: владелец сообщил, что отдельных соглашений на
H.264/AAC нет. Применимость патентных требований и полнота выполнения LGPL/
перелинковки ещё не установлены; публичный media-релиз не подписан и не создан.
Точные FFmpeg/CEF source archives и snapshot кода/сборки сохранены локально.
[Первичные источники, состав и следующие варианты](MEDIA_DISTRIBUTION_REVIEW.md).

Основной файл: `dist/ChroMinimum-0.0.1-alpha.8-setup-x64.exe`, 158397683 байта
(151,1 МиБ). SHA-256:
`ac427e0903fc71d03d3172436272b06981acd6211815d3f1861f1be203e1ec71`.
Рядом `.exe.sha256`; файл не подписан Authenticode и не опубликован.
Включены release media CEF, прежние About/window-state и fullscreen fix.
Дата сборки оболочки в About остаётся 22.10.2026: её DLL не перекомпилировалась.

Основной и TestInstall собраны из одного allowlisted payload (34 файла).
В финальный комплект включён полный generated Chromium CREDITS 8891390 байт;
старый sample preview отвергается упаковщиком. Все исполняемые SHA-256 до/после
исправления CREDITS одинаковы. Исторический portable ZIP ниже не изменён.

Приёмка отдельного TestInstall прошла: alpha.7 → alpha.8 EN и новая RU,
HTML/PDF/relaunch, NetworkService Low/AppContainer, floor=2 отказ до записи,
сохранение данных и удаление, неизменность основной регистрации и UserChoice.
Все установленные SHA-256 сверены с payload. Воспроизведение MP4/WebM/AAC через
installed launcher проверено до замены только внешнего CREDITS; код идентичен.
После замены повторена установка/хеши/HTML/PDF/sandbox/удаление, без повторного
media-прогона. Основная установка владельца не запускалась и не заменялась.

Updater: 33 обычных Rust-теста прошли (два прежних fixture-теста пропущены).
Новый отдельный ignored-тест на реальном архиве пройден явно: одноразовая
подпись, install → trial → health → active, критические SHA совпали с seed,
сеть/рабочий ключ/запуск браузера в этом тесте не использовались. Clippy
all-targets, Rustfmt и синтаксис изменённых Python прошли. Отдельный CLI-тест
подтвердил отказ на sample CREDITS без создания payload.

Три парных замера старого/нового launcher на **одном** release media ядре:
медиана запуска до JS 392,0 → 372,0 мс, private bytes дерева 184,76 → 198,17 МиБ,
CPU 0,0976 → 0,0781% всей машины. Launcher exe 2477056 → 2435072 байта.
Нулевая регрессия памяти не заявляется: +13,4 МиБ в малой серии, причина не
выделена. Свежие SSD-профили, фон/кэш ОС не изолированы, не first paint;
штатный launcher не остаётся в фоне (в smoke он специально ждёт браузер).

Архив обновления и неподписанные метаданные sequence=3 готовы локально в
`.local/alpha8-installer-20261023/`. Перед подписью sequence/срок и security floor
нужно проверить заново; sequence=2 был только локальным неопубликованным черновиком.
Media-пакет требует signed `media_codecs=true`; stock отклоняется.
[Контракт доставки](MEDIA_ENGINE_UPDATES.md).

**Media-канал пока не опубликован:** проверка обновлений вернёт ошибку доступности,
без загрузки stock CEF. Запуск и видео работают без доступности канала. До
публичного выпуска остаются проверка условий распространения кодеков, подпись
и публикация media-канала, сквозная сетевая приёмка. Stock workflow не менялся,
рабочий ключ не читался. Архивы/логи/хеши:
`docs/reports/alpha8-installer-20261023/`.

## Состав

- Существующие доработки About: логотип, сайт/GitHub, версии, центрирование.
- Существующие исправления сохранения normal/maximized/minimized состояния окна.
- Версия оболочки `0.0.1-alpha.8`; в About — дата сборки 22.10.2026.
- Экспериментальный CEF с H.264/AAC на закреплённых CEF 14c5a08 /
  Chromium 154.0.8037.98. Без ListAccounts-патча.
- USER32/SHELL32 загружаются отложенно: renderer не инициализирует UI DLL при
  загрузке оболочки. Проверки API/sandbox identity сохранены.
- Отключены метрики времени блокировок RecordLockAcquisitionTime из-за рекурсии
  отладочного instance tracer; защиты памяти не отключены.
- Патч 0003 переносит уничтожение извлечённого узла таблицы трекера за mutex.
  Предотвращает повторный вход через free hook GWP-ASan; не отключает его.

## Артефакт и границы

Каталог кандидата: `dist/ChroMinimum-0.0.1-alpha.8-media-preview-x64`.
Архив: `dist/ChroMinimum-0.0.1-alpha.8-media-preview-x64.zip`, 243000562 байта.
SHA-256: `888fc35d85b78c556bd8f6ded7a6375b3b4dc2e508094043d85201055e511006`.
Проверены CRC и список всех 41 файлов архива; профилей внутри нет.
Запуск для владельца — `Run-ChroMinimum.cmd`. Он задаёт отдельный профиль
`%LOCALAPPDATA%\ChroMinimum-Alpha8-MediaPreview` и выдаёт AppContainer только RX
на код runtime. Реальный профиль установленной alpha.7 не копируется.
Ассоциации, основная установка и публичные файлы не заменяются.

Это portable preview. Связка с updater/полным установщиком ещё не подготовлена:
stock-канал не должен незаметно удалять поддержку кодеков при обновлении ядра.
Прежний installer baseline не подменяется; исходники installer пока относятся
к опубликованной alpha.7. До публичной поставки нужны условия распространения
кодеков, выбранная схема обновлений и отдельная приёмка установщика.

## Проверки

- Rustfmt и Clippy `--release --locked --lib --bin bundle -- -D warnings` прошли.
- Media tooling: 6 тестов упаковщика, 6 проверок отчёта, 7 Node-тестов прошли.
- До патча 0003 финальная alpha.8 воспроизвела MP4 H.264 и WebM, декодировала
  AAC в ненулевой PCM, штатно закрылась; автоматическая проверка отчёта прошла.
  Данные: `docs/reports/alpha8-media-20261022/`.
- TLS-приёмка затем выявила отдельный startup deadlock instance tracer.
  Поэтому ранний media-успех не означает готовность первоначального бинарника.
- Патч 0003: первое/повторное применение прошли; изменённый исходник отклонён
  без дальнейшей записи. Инкрементальная компиляция — 362 шага за 2m57s.
- После патча 0003 финальные media-пробы и проверка отчёта прошли:
  `docs/reports/alpha8-media-fixed-20261022/`.
- Финальная security-приёмка на свежих SSD-профилях прошла: недоверенный
  сертификат отклонён без HTTP GET; обычный HTTPS загрузился; PDF загрузился;
  NetworkService Low/AppContainer, renderer Untrusted/restricted подтверждены.
  Отчёт: `docs/reports/alpha8-security-final-20261022/`. Полного аудита нет.
- Промежуточный HTTPS-прогон с новым профилем на E: завершился ERR_ABORTED по
  watchdog. Загрузка cookie store по NetLog заняла 13964 мс, в финальном SSD
  прогоне — 336 мс; это согласуется с [HTTP-диагностикой](HTTP_STARTUP_DIAGNOSIS.md).
  Для прямого bootstrap тест токенов дополнен явным `--direct-bootstrap`,
  поскольку прежний режим исключал root updater и терял root browser portable.
- UIA увидел окно alpha.8, версии, адресную строку и меню на stock CEF с новой
  оболочкой. Повторное открытие About через computer-use не выполнено:
  `coordinate input geometry is unavailable`, затем `FrameArrived timed out`.
  Существующие UI-проверки [соседней сборки](UI_INTEGRATION.md) сохраняются;
  новая визуальная приёмка не засчитана. Тестовое окно закрыто.
  Повторная UI-попытка затем остановлена пользователем Escape; UI-автоматизация
  прекращена, созданное нами пустое тестовое окно завершено.

## Измеренные расходы

Три парных прогона, одинаковая оболочка alpha.8, stock CEF против custom CEF,
с чередованием порядка. Для каждого запуска новый SSD-профиль; бинарники
предварительно хешированы, холодный кэш не контролировался, фон ПК не изолирован.
Компиляция завершена до серии. Все шесть процессов штатно закрылись с кодом 0.

| Метрика | Stock CEF | Custom CEF |
|---|---:|---:|
| Код и ресурсы runtime, без сжатия | 365,71 МиБ | 535,89 МиБ |
| Медиана запуска до loopback JS callback | 292 мс | 1238 мс |
| Медиана private bytes в раннем простое | 184,99 МиБ | 282,34 МиБ |
| Медиана суммы working set | 318,34 МиБ | 634,66 МиБ |
| Медиана CPU 5–10 с после callback, вся 16-поточная машина | 0,020% | 3,222% |

Запуск не означает первый видимый кадр. Сумма working set повторно учитывает
общие страницы. У stock время запуска варьировалось 290–2972 мс, у кандидата
1229–1286 мс; это маленькая локальная серия. Данные и подробные samples:
`docs/reports/alpha8-runtime-benchmark-20261022/`.

Изменились флаги сборки и диагностический instance tracer, поэтому вклад одних
кодеков не выделен. Текущая non-official конфигурация заметно тяжелее stock и
**не рекомендована для основного лёгкого обновления**. Следующий технический
этап перед выпуском — производственная конфигурация и повтор расходов/приёмки.
Новая длительная сборка этим шагом не запускалась.

Поведение hdrezka с авторизацией, разные DPI/мониторы и старые GPU отдельно
не подтверждены. Следующий пользовательский шаг — ручной запуск preview и
проверка сайта на отдельном профиле.

Карта исходников, символов и найденных причин: [CEF_KNOWLEDGE](CEF_KNOWLEDGE.md).
