# ChroMinimum 0.0.1-alpha.8 — черновик Windows x64

Статус: сохранённый локальный кандидат. Этот текст не означает одобрение
публичного распространения media-комплекта или готовность канала обновлений.

2026-10-24 владелец выбрал media-выпуск. Подготовлен отдельный комплект
`dist/ChroMinimum-0.0.1-alpha.8-media-candidate-20261024/`; повторная installed
media-приёмка EN/RU подтвердила MP4/WebM и ненулевой AAC PCM. Сохранён прежний
проверенный бинарный состав, дата оболочки в About остаётся 22.10.2026.

## Изменения кандидата

- Экспериментальная сборка CEF с H.264/AAC: проверены локальные видеоформаты;
  владелец подтвердил воспроизведение hdrezka на своём устройстве.
- Исправлено скрытие панели навигации при полноэкранном видео.
- Доработано окно About: логотип, сайт/GitHub, версии и центрирование.
- Исправлено сохранение и восстановление обычного, развёрнутого и свёрнутого
  состояния окна.
- Установщик и updater учитывают требуемые возможности media-ядра:
  обновление не должно незаметно заменять его стандартным CEF без кодеков.

## Проверка производительности

Локальная серия на Windows 10 / Ryzen 7 3700X / RX580: 75/75 попыток
startup/idle/video/game приняты. CM быстрее достигал готовности локальной
страницы и выделял меньше private bytes в простое и игре; при видео
private bytes выше соперников, игровой CPU выше UC. Плавность выбранных
видео/игры сохранена.

312 мс — запуск непосредственно core bootstrap на прогретом кэше ОС,
а не замер установленного launcher/updater. Это не обещание такого времени
на произвольном сайте, другом компьютере или новом бинарном составе.
[Методика, версии и результаты](RESOURCE_RESULTS_20261024.md).

## Ограничения кандидата

- Ранняя экспериментальная версия, без вкладок и законченной системы
  загрузок, разрешений сайтов и popup. Поддержка WebExtensions не принята.
- Проверена Windows 10 build 19045 x64; настройки установщика допускают
  Windows начиная с build 19041, что не заменяет испытания на каждой версии.
- Применимость условий распространения H.264/AAC и полнота LGPL/relinking
  комплекта пока не установлены. [Статус](MEDIA_DISTRIBUTION_REVIEW.md).
- Media-канал не опубликован; проверка обновлений этого кандидата может
  вернуть ошибку доступности. До публичного выпуска требуется рабочая
  проверенная доставка обновлений.
- Установщик не подписан Authenticode. Подпись метаданных updater — отдельная
  проверка, её нельзя выдавать за подпись Windows-установщика.
- Тесты sandbox/TLS не заменяют независимый аудит безопасности.
