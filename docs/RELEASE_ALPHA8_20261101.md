# ChroMinimum 0.0.1-alpha.8 — Windows x64, 1 ноября 2026

## Изменения

- H.264/AAC через системные декодеры Windows, включая AAC в WebAudio.
  Проверено на текущем ПК; доступность зависит от компонентов Windows и GPU.
- Исправлен fullscreen: панель браузера скрывается и восстанавливается.
- Штатная мини-панель загрузок привязана к кнопке. Прогресс показан кольцом;
  значок скрывается на время загрузки и возвращается после неё.
- Пустая история загрузок открывается в текущем окне, без отдельного Chromium.
- Доступные и недоступные кнопки различаются; сохранены native hover/press/Tab
  и переключение Обновить/Стоп. Убраны лишние рамки внутри иконок.
- Логотип ChroMinimum на странице загрузок, проверен в светлой/тёмной CSS-теме.
- Общие внешние протоколы обрабатываются штатным подтверждением Chromium.

## Установка

Это полный установщик: новый адаптер должен попасть в доверенный seed.
Обычное обновление одного ядра со старым адаптером этот переход не заменяет.
Установщик не назначает браузер приложением по умолчанию без выбора владельца.
Тесты используют отдельные данные; рабочий профиль владельца агент не открывал.

## Проверки и ограничения

Проверены пустая история/скачивание/отмена/обрыв без второго окна, glyph/ring,
кнопка/Ctrl+J/resize/back, MP4/WebM EOF, AAC PCM и системные декодеры, sandbox,
fullscreen API/Escape. Финальная RC TestInstall проверена отдельно EN/RU:
миграция seed, hash всех файлов, HTML/PDF/relaunch, branding, удаление,
сохранение данных и неизменность основной регистрации/UserChoice.

Это экспериментальная alpha. Сравнительные CPU/RAM/startup замеры после UI
изменений не выполнялись. Полная unattended media-приёмка чувствительна к
видимости окна; успешные и остановленные прогоны сохранены в отчётах.
Не заявляется поддержка всех GPU, Windows N или DRM-сервисов.

Сборка локальная, без Authenticode и без публикации на сайте/GitHub.
Пакет исходных материалов содержит текущую оболочку, патчи, recipe и базовые
Git-архивы CEF/FFmpeg; это не утверждение о полном выполнении условий
распространения. Старые установщики сохранены.
