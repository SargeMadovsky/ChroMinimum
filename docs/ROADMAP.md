# План разработки

Начато исследование. Уточнение владельца от 2026-10-19 меняет ближайший порядок: инструменты → безопасный запуск → одно окно с навигацией и PDF → надёжность → исследование расширений → модули. Проверка MV2 и uBO не блокирует первый базовый прототип; окончательный выбор движка для расширяемого продукта остаётся открытым. Таблица ниже сохраняет общие направления; зависимости расширений применяются при возвращении к ним. Сроки оцениваются после исследования. Неразрешённый блокер не считается успешным завершением.

| Этап | Результат | Условия завершения |
|---|---|---|
| 00. Пригодность архитектуры | Прототипы движка, UI и расширений; решение о стеке | Выполнен STAGE_00; известна стоимость MV2 и blocking API; выбран или отклонён кандидат |
| 01. Минимальный браузер | Windows-сборка с одной страницей | Навигация, ввод, HTTPS, профиль, файлы, popup, разрешения; нет оставшихся процессов |
| 02. Надёжность | Устойчивое ядро и путь обновления | Сбой renderer, профиль, приватный режим, восстановление, обновление и ошибки проверены |
| 03. Платформа расширений | Поддерживаемое подмножество WebExtensions | Повторяются испытания uBO/Tampermonkey; разрешения, UI, обновление и отключение проверены |
| 04. Дополнительные модули | Вкладки, закладки, история, загрузки по одному | Каждый модуль имеет отдельную приёмку; базовый режим работает без них |
| 05. Производительность | Воспроизводимые сравнительные отчёты | BENCHMARKS; устранены подтверждённые накладные расходы; нет регрессий безопасности |
| 06. Независимость движка | Проверенная политика соединений и сборки | Аудит трафика, нужные патчи, лицензии, своевременные обновления |
| 07. Релизы и платформы | Установка, обновления, Linux/macOS по очереди | Матрица платформ, проверка поставки и документация поддержки |

Проверки безопасности, приватности и стоимости обновлений начинаются на этапе 00 и продолжаются постоянно. Этап 06 расширяет их, а не откладывает до конца.

## Контрольные версии

- Prototype: только технические эксперименты, без рекомендации для повседневного сёрфинга.
- Milestone 1: минимальный Windows-браузер; архитектурная проверка расширений уже проведена, полноценный менеджер расширений ещё может отсутствовать.
- Alpha: ядро, испытанная совместимость выбранных расширений и первые модули.
- Beta: стабильные разрешения, обновления, проверки приватности и воспроизводимая поставка.
- 1.0: заявленные функции подтверждены, обновления движка отработаны, проведена независимая проверка безопасности. Собственный форк не обязателен, если цели достигаются без него.

## Зависимости

Этап 03 использует доказательства 00 и стабильное ядро 02. Исследование расширений нельзя откладывать на 03. GUI не выбирается окончательно до проверки его совместимости с необходимым стилем браузера. Оптимизации не заменяют функциональную приёмку.
