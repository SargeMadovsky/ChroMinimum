## Как изменять решения

### D016 — публичная публикация, 2026-10-19

По явному выбору владельца: публичный SargeMadovsky/ChroMinimum, собственный код под MIT. Выпуск — экспериментальный prerelease 0.0.1-alpha.1, без утверждения о завершённой security-приёмке. Локальные отчёты, профили и кеши не публикуются. Linux x64 и macOS ARM64 проходят отдельные сборки и smoke-проверки в GitHub Actions; поддержка не объявляется подтверждённой до фактических результатов.

Новая запись: ID, дата, статус, проблема, варианты, доказательства, выбор, последствия и ссылки на отчёты. Старую запись помечать заменённой с новым ID. Не переписывать историю так, будто отклонённый вариант никогда не рассматривался.

## Открытые вопросы перед реализацией

Точная версия CEF/cef-rs; доступность MV2 и нужных сетевых API; UI расширений в минимальной оболочке; фактическая изоляция; цена переноса патчей; ресурсы сборки; лицензирование; канал обновления и ответственность за security fixes.
