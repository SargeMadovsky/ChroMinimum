завершённую приёмку публичного установщика и доставки обновлений.

## Выбранный media-кандидат — 2026-10-24

Владелец выбрал полноценное видео в рамках проверенных H.264/AAC/WebM.
Состав закреплён [D035](DECISIONS.md); stock-вариант не готовится вместо него.
Комплект: `dist/ChroMinimum-0.0.1-alpha.8-media-candidate-20261024/`,
26 файлов / 197133754 байта (около 188,0 MiB), включая установщик
158397683 байта (151,1 MiB), лицензии, исходные материалы, отчёты и checksums.
Сохранён принятый бинарный состав: компиляция CEF/оболочки не выполнялась,
дата оболочки в About остаётся 22.10.2026.

Новая installed media-приёмка EN/RU прошла через TestInstall launcher:
MP4 H.264/AAC и WebM — currentTime>0,3 с, readyState=4, 16/15 decoded frames;
AAC — 123244 decoded PCM frames, 2 канала, 44100 Hz, peak≈0,0991.
Проверены alpha.7→alpha.8, payload hashes, HTML/PDF/relaunch,
NetworkService Low/AppContainer, security floor refusal, сохранение данных
и удаление, неизменность основной регистрации/UserChoice.

Два предшествующих отказа сохранены: профиль на E: не дождался первого HTTP
fixture, профиль на C: загрузил документ, но скрытые video elements остались
без playback, при этом AAC PCM декодировался. У диагностического инструмента
добавлен --visible: Windows SW_HIDE не задаётся, Page.bringToFront выполняется
без эмуляции видимости и document.visibilityState проверяется до медиапроб.
Installer media-тест вызывает этот режим. Финальный успешный прогон использует
синтетические TEMP-профили на C:. Причина первого тайм-аута не доказана;
изменение диска само по себе не объявляется исправлением приложения.
Код и защитные параметры браузера не изменялись.

Проверены 25 строк SHA256SUMS, 7 Node lifecycle-тестов и 6 Python тестов
проверки media-отчёта. Упаковщик привязывает результаты к SHA TestInstall,
не смешивает media из разных установок и заново проверяет decoded frames/PCM.
Наличие исходных материалов не объявляется полным выполнением LGPL/relinking.
Manifest сохраняет public_distribution_ready=false и update_channel_published=false.

[Итог и архив успешных/неуспешных проб](reports/alpha8-media-candidate-20261024/audit.json).
Полноценное видео здесь не означает поддержку всех кодеков/сайтов/DRM.

SHA-256 повторно проверен 2026-10-24:
`ac427e0903fc71d03d3172436272b06981acd6211815d3f1861f1be203e1ec71`.
Кандидат содержит About/window-state/fullscreen исправления и official media
CEF. Его пересборка только ради новой даты не требуется.

Все 26 записей manifest runtime, использованного в сравнении, совпадают
с core/seed архивного принятого payload по размеру и SHA-256. Это сверка
манифестов; новый запуск установщика в этой проверке не выполнялся.
Полная прежняя приёмка: [alpha.8](RELEASE_ALPHA8.md).

## Что закрыто новой серией

- 75/75 попыток startup/idle/video/game приняты на закреплённом runtime.
- В выбранных сценариях сохранена плавность, определены преимущества и проигрыши.
- Подготовлены иллюстрации, тексты и HTML-блок для сайта.

Запуск в сравнении выполнялся непосредственно через bootstrap из core runtime,
не через установленный launcher/updater. Число 312 мс нельзя без отдельного
замера приписывать полному установленному пути запуска. Новые бинарники либо
иной CEF также нельзя объявить эквивалентными измеренной сборке без сверки.

## Оставшаяся подготовка

### Выполненная сверка и повторная приёмка

Точный source snapshot v2 проверен по SHA-256 из source-materials.json.
108 файлов совпали побайтово; четыре отличаются: обзор распространения,
apply-cef-patches.py, diagnose-media.cjs и src/lib.rs. Новых application source
файлов вне snapshot в src/ и updater/src/ нет. Изменение lib.rs добавляет
экспериментальный --test-platform-aac внутри smoke + --test-cdp; оно не включено
в принятый runtime. Код updater и installer policy совпадают со snapshot.
Это не заявление о побитовой воспроизводимости из исходников.

Все 34 файла сохранённого payload-final и 26 файлов тестового runtime
дополнительно прочитаны и сверены с принятыми SHA-256; расхождений нет.
Принят существующий бинарный состав, повторная компиляция текущего дерева
с тестовыми экспериментами для этого кандидата не выполняется.

Повтор TestInstall (отдельная регистрация): alpha.7 → alpha.8 EN и новая RU
прошли. Проверены все установленные payload SHA, HTML/PDF, relaunch,
NetworkService Low/AppContainer, отказ при security floor=2 до копирования,

регистрация основной установки не изменены. Выполнение — рабочая Windows-
учётка, только синтетические данные; это не новая сравнительная серия ресурсов.
Installed media в этом повторе не запускался: повтор использует те же бинарники,
что [прежняя installed media приёмка](RELEASE_ALPHA8.md); флаг

### До публичного выпуска

1. Состав ядра выбран: media CEF с H.264/AAC. Остаются условия распространения;
   проект сообщил об отсутствии отдельных соглашений. В документации остаются
   нерешёнными применимость условий распространения и полнота LGPL/relinking
   комплекта. Это сохранённый статус проверки, не новое заключение о законности.
   [Исходные материалы и ограничения](MEDIA_DISTRIBUTION_REVIEW.md).
   Переход на stock CEF изменит поддержку видео и не является молчаливой заменой.
2. Сверка текущих изменений с включённым бинарным составом выполнена выше;
   не включать экспериментальные MF/AAC патчи в принятый runtime автоматически.
   При изменении состава собрать новый ограниченный кандидат и повторить
   затронутые проверки. Старый принятый установщик сохранить.
3. После определения публичного состава подготовить согласованный канал
   обновлений: актуальные sequence/expiry/security floor, подпись метаданных
   и сквозную сетевую приёмку. Media-канал текущего кандидата пока не опубликован;
   замена на stock запрещена его policy. Authenticode установщика и подпись
   метаданных updater — разные механизмы, не смешивать их.
4. Повторить ограниченную финальную приёмку именно поставляемого установщика:
   новая изолированная установка/обновление alpha.7, запуск через launcher,
   About, видео/fullscreen, PDF, sandbox, обновление/отказ/откат и удаление
   с сохранением данных. Использовать только синтетические тестовые профили.
5. Подготовить release notes, checksums, состав лицензий/исходников и ссылки
   сайта на утверждённые файлы; отдельно согласовать публичную публикацию.

Блокирующие вопросы публичной готовности сейчас — состав/условия media-поставки
и рабочая доставка обновлений, а не необходимость ещё одной оптимизации
ради прохождения тестов плавности. Полный 48-минутный цикл без изменения
runtime повторять не требуется.
