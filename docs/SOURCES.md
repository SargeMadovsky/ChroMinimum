# Источники и статус утверждений

Дата подготовки: 2026-10-19. Источники помогают исследованию, но не заменяют проверку конкретного бинарника.

## Замысел продукта

Требования получены от владельца проекта; публичная спецификация находится в PRODUCT.md и EXTENSIONS_POLICY.md. Внутренняя переписка не публикуется.

Приоритет последней поправки: WebExtensions перед собственным WASM; испытание полного uBO до выбора движка; tabs/windows API ядра независимо от панели вкладок.

## Первичные технические источники

- [CEF tutorial](https://chromiumembedded.github.io/cef/tutorial): различает Chrome style и Alloy style. Конкретный выбор проверяется для закреплённой версии.
- [Удаление Alloy bootstrap, M128](https://github.com/chromiumembedded/cef/issues/3685): история перехода и ограничения extension API по стилю. Нельзя механически переносить старое описание двух runtime на текущую версию.
- [CEF architecture](https://github.com/chromiumembedded/cef/blob/master/docs/architecture.md): полезна для общей модели; ограничения Views/OSR сопоставлять с актуальными headers, примерами и версией, поскольку текст содержит исторические формулировки.
- [cef-rs README](https://github.com/tauri-apps/cef-rs/blob/dev/README.md): сборка и упаковка, в том числе sandbox. Доступность параметра сборки не доказывает фактическую работу защиты.

## Что ещё не подтверждено

В этом проекте не проверялись поддержка MV2 в актуальном CEF, полный uBO, восстановление удалённых API, совместимость Slint, накладные расходы и отсутствие нежелательных соединений. Эти вопросы вынесены в этап 00.

Даты прекращения поддержки манифестов, версии расширений и расписания релизов из прежнего ответа не используются как нормативные факты. Перед реализацией проверять их заново. В отчётах сохранять версии, commit/permalink и дату доступа вместо одной ссылки на подвижную ветку.
