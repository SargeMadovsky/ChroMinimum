# Maxthon 3 как ориентир: какие функции брать

Статус: предложение 2026-11-22. Код не менялся, ничего не реализовано.
Все затраты ниже — **оценки**, а не замеры. Каждую функцию до реализации
отдельно согласует владелец ([performance.mdc](../.cursor/rules/performance.mdc)).

## Источники

- Локальная установка владельца `C:\Program Files (x86)\Maxthon3`, версия
  **3.4.3.600** (дата сборки в `Bin\mxver.db` — 2012-10-12). Прочитаны
  `Language\en.ini` и `ru-ru.ini` (UTF-16; 92 раздела — меню, настройки,
  диалоги всех встроенных функций) и состав `Modules\` и `Addons\`. Браузер
  не запускался: по словам владельца, современные сайты в нём почти не
  открываются.
- [Блог Maxthon, «What's cool about Maxthon 3?», 2011](https://blog.maxthon.com/?p=216):
  жесты, Undo, Quick Access, AdHunter, Magic Fill, загрузчик, скины.
  Там же сказано, что ранний MX3 не имел split screen и алиасов из MX2;
  в 3.4.3 они уже есть в языковом файле.
- Скриншот владельца: Maxthon 3 с вкладками в заголовке окна, одной панелью
  инструментов и строкой состояния.

## Полный инвентарь Maxthon 3.4

Из меню, настроек и модулей установленной версии:

| Группа | Функции |
|---|---|
| Вкладки | Undo закрытой, дублировать, закрепить (Lock Tab), закрыть другие/слева/справа, список вкладок, закрытие двойным/правым кликом, позиция новой вкладки, после закрытия переходить к последней посещённой |
| Сессии | Последняя и более ранние сессии, «Открыть все», выход с подтверждением при нескольких вкладках |
| Адресная строка | Smart Address Bar (подсказки из истории/избранного), URL Alias (`gg` → сайт, F1–F12 → сайт, `g запрос` → поиск нужным движком), Paste & Go / Paste & Search, правый клик по «+» = вставить и перейти |
| Страница | Reader Mode (цвета, шрифт, ширина, автоподгрузка следующей страницы, авто для домена), Night Mode (свои цвета, автопереключение), масштаб по умолчанию, автообновление с интервалом, перевод, печать с предпросмотром |
| Инструменты | Snap (область/вся страница, стрелки, размытие, текст), Resource Sniffer (видео/аудио/картинки страницы), всплывающее видео (Video Popup), Feed Reader, SkyNote (заметки), внешние программы (External Tools), Express Lookup |
| Управление | Мышиные жесты (свои, цвет следа, rocker-жесты колесом/двумя кнопками), Super Drag & Drop, свои горячие клавиши, Boss Key, Mute, Ctrl+клик — быстро сохранить картинку |
| Защита | AdHunter (правила, блокировка кликом, журнал), блокировщик popup, Magic Fill (пароли и формы), Safe URL Checker, приватное окно, Do Not Track, свой User-Agent, прокси |
| Окно | Split Screen, Quick Access (плитки), панель избранного, боковая панель, строка состояния (масштаб, звук, popup, AdHunter), скины, «Customize UI», сворачивание в трей, только одно окно |
| Сервисы | Passport, синхронизация, облачные заметки, push-сообщения (`MxMsgPush`), программа «улучшения качества» (`MxUeip`), центр скинов и приложений онлайн, загрузчик Thunder (Xunlei) |
| Движок | Два движка: Ultra (WebKit) и Retro (Trident/IE) с автоматическим выбором |

## Фильтр

Функция остаётся кандидатом, если:

1. полезна в сценарии «один сайт, одно окно» или станет полезна вместе с вкладками;
2. не создаёт фоновых служб, таймеров и сетевых соединений вне явного действия;
3. не требует аккаунта, облака или телеметрии (P06);
4. не дублирует то, что уже даёт Chromium или будет давать WebExtension
   (EXTENSIONS_POLICY: расширения — основная экосистема).

## A. В ядро или оболочку сейчас — почти бесплатно

Работают без вкладок. Ожидаемая цена: ноль фоновой работы, единицы КБ кода,
нулевой вклад в запуск, если функция выключена.

| # | Функция | Почему удобно | Затраты (оценка) и как |
|---|---|---|---|
| A1 | **URL-алиасы и ключевые слова поиска**: `gg`, `w запрос`, F1–F12 → сайт | Главный ускоритель для «одного сайта»; ложится в `address_input.rs` | Таблица в небольшом файле настроек; чтение при старте или лениво при первом вводе. Сеть — только переход, о котором попросил пользователь. Поиск из адресной строки (SHELL_REVIEW 1.1) — предпосылка. |
| A2 | **Восстановить последнее закрытое** (окно popup, позже вкладку) и **«Последняя сессия»** при запуске (по умолчанию выключено) | Случайно закрыл — вернул; продолжить с того же сайта | Список в памяти; запись URL на диск только при закрытии и только если включено (приватность истории — PRODUCT). |
| A3 | **Без звука для страницы** + значок «играет звук» в адресной строке | Нужно и без вкладок: фоновое видео/реклама | `CefBrowserHost::SetAudioMuted` есть в API. Событие о звучании — **проверить** в CEF 154 (опроса не делать). |
| A4 | **Автообновление страницы** с интервалом | Дашборды, мониторинг, очереди — типичный сценарий «одного сайта» | Один таймер только пока режим включён для текущей страницы; мин. интервал (например 5 с) против случайной нагрузки на сайт. |
| A5 | **Boss Key** — глобальная клавиша спрятать/показать окно | Дешёвая и любимая функция Maxthon | `RegisterHotKey` в Windows: событие ОС, без потока и опроса. Выключено по умолчанию; Linux/macOS отдельно. |
| A6 | **«Открыть в системном браузере»** (наследник External Tools) | Сайт сломан в минимальном браузере → одно действие, а не копировать URL | Пункт меню + `ShellExecute`/`open`. Только по нажатию. |
| A7 | **Вставить и перейти** (Ctrl+Shift+V или пункт меню) | Частое действие, у Maxthon на правом клике по «+» | Чтение буфера только по команде. Можно ли добавить пункт в контекстное меню Textfield CEF Views — **проверить**. |
| A8 | **Индикатор масштаба ≠ 100%** рядом с адресом, клик — сброс | Аналог «100%» в строке состояния Maxthon без самой строки | Chromium уже хранит масштаб по сайтам; нужен только значок по событию изменения. |

## B. Вместе с модулем вкладок (этап 04)

Не строить без вкладок. Каждая — часть модуля, не отдельные службы.

| # | Функция | Затраты (оценка) |
|---|---|---|
| B1 | Undo закрытой вкладки (кнопка + Ctrl+Shift+T), дублировать, закрепить, закрыть другие/справа | Список в памяти; дешёво. |
| B2 | Закрытие средней кнопкой/двойным кликом, позиция новой вкладки, после закрытия — к последней посещённой | Только логика модуля. |
| B3 | Список вкладок (меню со всеми вкладками) | Меню строится при открытии. |
| B4 | **Quick Access** как локальная страница новой вкладки: плитки, заданные пользователем | Локальная HTML-страница из поставки; без миниатюр по сети, без «популярного» из истории. Первая открытая новая вкладка стоит renderer — как любая страница. |
| B5 | **Split Screen** — две страницы в одном окне | Второй BrowserView = второй renderer (десятки–сотни МБ в зависимости от сайта). Только по команде. Нужен замер. |
| B6 | Вкладки в заголовке окна, как на скриншоте Maxthon | Экономит строку по высоте, но требует своей рамки окна на каждой платформе (DPI, Snap Windows, перетаскивание). Дорого в разработке, не в ресурсах. Решать после прототипа вкладок. |

## C. Через WebExtensions — не встраивать

Эти функции Maxthon встроил, но в ChroMinimum их естественный путь —
расширения после проверки платформы (EXTENSIONS_POLICY). Встраивание
каждой добавило бы постоянную нагрузку на все страницы (content script,
правила) у пользователей, которым она не нужна.

| Maxthon | Путь в ChroMinimum |
|---|---|
| AdHunter, блокировка кликом | uBlock Origin (контрольное расширение) |
| Magic Fill | Встроенный менеджер паролей Chromium или Bitwarden |
| Мышиные жесты, Super Drag & Drop | Расширение. Нативная реализация требует перехвата мыши в окне renderer на каждой платформе; дорого и хрупко. |
| Night Mode | Dark Reader. Флаг принудительной тёмной темы Chromium — **проверить** в CEF, вероятно только при запуске. |
| Reader Mode | Расширение. Режим чтения Chrome живёт в боковой панели; наличие в CEF не проверено. |
| Resource Sniffer, Video Popup | Расширение. Картинка-в-картинке уже есть в Chromium для `<video>`. |
| Feed Reader, перевод, Express Lookup | Расширения; перевод требует внешнего сервиса. |
| Snap с редактором | Простой снимок страницы в файл возможен позже через DevTools-метод `Page.captureScreenshot`; редактор с размытием и стрелками — не наша задача. |

## D. Отклонить

| Функция | Причина |
|---|---|
| Passport, синхронизация, облачные заметки и избранное, Lock Maxthon через Passport | Обязательный аккаунт и облако (P06, AGENTS.md) |
| Программа «улучшения качества» (`MxUeip`), push-сообщения (`MxMsgPush`), советы в строке состояния, всплывающие сообщения браузера | Телеметрия и навязанные сервисы (P06) |
| Safe URL Checker | Облачная проверка каждого адреса; Chromium Safe Browsing — отдельное решение о сети |
| Multi-Search (несколько движков сразу) | Умножает сетевые запросы; алиасы (A1) закрывают ту же потребность |
| Retro mode / второй движок | Trident мёртв и небезопасен; совместимость со старыми сайтами не цель |
| Thunder и другие сторонние загрузчики | Сторонний нативный код в процессе браузера (AGENTS.md) |
| Центр скинов и приложений онлайн | Сеть и сервис; локальные темы — модуль из PRODUCT, если понадобятся |
| Боковая панель с веб-панелями | Постоянно живые renderer-процессы |
| Сворачивание в трей, «работать в фоне» | Противоречит «закрыл окно — браузер завершён» |

## Визуальные ориентиры со скриншота

- **Одна панель инструментов** с компактными значками; это уже есть.
- **Индикаторы внутри адресной строки** (замок, звезда, режим чтения):
  у нас так уже сделан индикатор соединения; звук и масштаб (A3, A8) лучше
  ставить туда же, а не в отдельную строку состояния.
- **Строка состояния** Maxthon стоит ~22 px высоты на каждой странице;
  Chromium уже показывает адрес под курсором всплывающей подсказкой.
  Предлагаю не добавлять её.
- **Кнопки «Домой» и «Undo»** на панели — только как настраиваемые
  (Customize UI): по умолчанию панель остаётся минимальной.
- **Вкладки в заголовке окна** — см. B6.

## Предлагаемый порядок

1. A1 после поиска из адресной строки — максимальная польза при нулевой цене.
2. A3 и A8 — индикаторы в адресной строке. **Сделано 2026-11-26** (D049): mute и масштаб; значка «играет звук» нет — в CEF 154 нет события.
3. A6, A7, A5 — короткие команды меню и клавиши.
4. A2 и A4 — требуют небольшого файла настроек; вместе решить, где он лежит.
5. Группа B — в составе модуля вкладок, Split Screen — после замера.

Открытые вопросы владельцу: какие из A брать в первую очередь; нужна ли
настройка панели (Customize UI) раньше вкладок; Split Screen — в ядре или
только в модуле вкладок.
