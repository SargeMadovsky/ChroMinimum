# Продукт и требования

Статус: исходная спецификация, 2026-10-19. Рабочее название — ChroMinimum.

## Назначение

Быстрый браузер для веб-сёрфинга, который пользователь расширяет сам. Ориентир — минимальная оболочка готового современного движка, как идея надстройки Maxthon над IE, без попытки повторить ресурсные показатели старого веба.

## Обязательные требования

| ID | Требование | Как принимается |
|---|---|---|
| P01 | Chromium и оболочка преимущественно на Rust | Зафиксированы версии, границы Rust/C++ и способ сборки |
| P02 | Минимальный режим без дополнительных модулей | Одна страница, URL/поиск, назад/вперёд/обновить/стоп |
| P03 | Современный веб | HTTPS, cookies, формы, авторизация, файлы, видео и ввод проверены |
| P04 | Расширяемость и свобода установки | Матрица MV2/MV3 и испытания из EXTENSIONS_POLICY |
| P05 | Безопасность обязательна | Sandbox, TLS, изоляция, разрешения и обновления проверяются всегда |
| P06 | Нет навязанных сервисов | Нет рекламы оболочки, аккаунта браузера и телеметрии |
| P07 | Низкие накладные расходы | Публикуются замеры по BENCHMARKS, без выдуманных процентов |
| P08 | Открытая разработка | Выбрана лицензия и учтены лицензии зависимостей до публикации |

## Разделение функций

Ядро: жизненный цикл страниц и окон, навигация, сеть, профиль, разрешения, безопасная загрузка файлов, базовый UI, обновления и инфраструктура расширений. Семантика tabs/windows существует даже без панели вкладок.

Дополнительные модули: панель вкладок, закладки, поиск по истории, расширенный список загрузок, управление сессиями, жесты, темы. История посещений записывается только при включённой соответствующей функции; cookies и данные сайтов — отдельная подсистема ядра.

Веб-расширения: блокировщики, пользовательские скрипты, менеджеры паролей и другие WebExtensions. Собственный блокировщик не заменяет проверку полноценного uBlock Origin.

## Границы первой версии

Уточнение владельца от 2026-10-19: сначала реализовать просмотр интернета и PDF, без вкладок и плагинов. Проверка расширений больше не является обязательной перед этим базовым прототипом. Движок используется как предварительный выбор; цели будущей платформы расширений сохраняются.

PDF: открытие документов по HTTP(S) и локального файла по явному выбору пользователя, прокрутка, масштаб, выбор страниц, поиск текста и сохранение. Использовать встроенный PDF viewer Chromium, если он доступен в выбранной поставке; отдельный PDF-движок не добавлять без необходимости. Проверка должна включать PDF с корректным Content-Type и файл с диска.

Windows x64; одна страница, работающие базовые сценарии, тестовый профиль и корректное закрытие процессов. Магазин, плагины, синхронизация, мобильные версии, AI-функции и собственный WASM runtime не входят в первый прототип.

Минимальный режим не запрещает popup и новые страницы: ядро должно безопасно обработать их, например отдельным окном, по документированной политике.

## Управление компромиссами

Не жертвовать безопасностью ради скорости. Не объявлять CEF выбранным, пока не проверена цель расширений. Если цели несовместимы с доступным способом интеграции, представить владельцу результаты и стоимость вариантов; не сокращать требования молча.
