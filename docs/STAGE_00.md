# Этап 00: проверка архитектуры

Статус: начато исследование. Уточнение владельца от 2026-10-19: сначала минимальный браузер для сайтов и PDF. Сейчас выполняются подготовка инструментов, безопасный запуск и базовая навигация/PDF; пункты про расширения и окончательный выбор платформы откладываются до отдельного возвращения к ним. Ни один непроведённый эксперимент не считается успешным.

## Последовательность

1. Проверить инструменты Windows x64, свободное место, SDK, Rust/C++ toolchain и условия распространения зависимостей. Не скачивать исходники всего Chromium до оценки необходимости.
2. Закрепить точные версии Chromium/CEF, cef-rs, toolchain и архитектуру. Записать источники бинарников и проверку их целостности.
3. Запустить минимальный официальный пример с песочницей, GPU, вводом, resize и корректным завершением. Проверить фактические процессы и настройки изоляции.
4. Проверить загрузку расширений, popup/options, фоновые контексты, content scripts и сообщения в поддерживаемом стиле CEF. Отдельно подтвердить MV2 и blocking API.
5. Прогнать uBlock Origin и Tampermonkey на локальных тестовых страницах; закрепить версии расширений и права на тестовые артефакты. Простого появления иконки недостаточно.
6. Добавить минимальный нативный ввод адреса и проверить совместимость с тем же режимом движка. Сначала использовать наиболее прямой поддерживаемый путь; оценивать Slint лишь по результатам интеграции.
7. Измерить старт, память и простой; проверить исходящие соединения. Оценить обновление на следующую доступную поддерживаемую версию.
8. Сравнить варианты и записать решение в DECISIONS, обновить ARCHITECTURE и TASKS.

## Матрица экспериментов

| Проверка | Доказательство |
|---|---|
| Chromium + Rust запускается | Команды, версии, журнал и запись ручной проверки |
| Sandbox/GPU/изоляция | Конфигурация, runtime-данные и наблюдаемое поведение |
| MV2 и MV3 | Manifest, версия расширения, ожидаемое и фактическое поведение отдельно |
| uBO: сетевая фильтрация | Локальный сервер фиксирует отсутствие заблокированного запроса и наличие разрешённого |
| uBO: cosmetic/scriptlets | Контрольный DOM и эффект scriptlet; один скрытый элемент не доказывает все возможности |
| Tampermonkey | Скрипт, соответствие URL, запуск и хранение значения после перезапуска |
| UI расширения | Popup/options открываются, имеют правильные origin и права |
| Нативный UI | Навигация, фокус, IME, DPI, resize и отсутствие лишних копирований по возможности |
| Закрытие | Все подпроцессы завершаются, профиль открывается повторно |
| Обновляемость | Зафиксирован размер патчей и воспроизводимость переноса, либо явный блокер |

## Варианты решения

A. Стандартный CEF удовлетворяет требованиям: выбрать его и минимальный поддерживаемый UI.

B. Нужны патчи CEF/Chromium: перечислить удалённые API, зависимости, объём изменений и стоимость каждого обновления. Проверить прототип патча, не заменять результат предположением.

C. Нужен отдельный форк Chromium: описать C++-часть, ресурсы сборки, CI и сопровождение; представить владельцу выбор до основной реализации.

D. Нет приемлемого безопасного варианта: этап заканчивается документированным отрицательным результатом. Не выдавать MV3 Lite за выполнение требования полного uBO.

## Формат отчёта

Дата/машина → версии и команды → сценарии → ожидаемое/фактическое → журналы и артефакты → ограничения → сравнение вариантов → решение. Непроверенное отмечать «не проверено», а не «поддерживается».
