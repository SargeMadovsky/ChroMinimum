# ChroMinimum 0.0.1-alpha.9 — Windows x64, 22 ноября 2026

## Изменения

- Кнопка состояния соединения открывает штатную страницу безопасности Chromium
  (PageInfo/SSL) вместо самописной панели. По нажатию окно показывается сразу,
  без промежуточных панелей и кнопок возврата (D043).
- Просмотр сертификата открывается штатным окном Chromium. Первое открытие на
  тестовом стенде занимало 57–91 мс; прежние ~2 с владельца на стенде не
  воспроизведены (устранена задержка CEF `GetNewBrowserInfo`, патч 0017).
- Других функций нет. Ядро CEF 154.0.34 (Chromium 154.0.8037.98) с системными
  H.264/AAC alpha.8 сохранено, кроме патчей 0016 и 0017.

## Установка

Полный установщик: ядро и оболочка заменяются вместе. Обновление поверх alpha.8
проверено в TestInstall (данные сохраняются). Браузером по умолчанию установщик
не назначается.

## Проверки

- TestInstall EN/RU: отказ при более высоком security floor до копирования,
  обновление с alpha.8, хеши всех файлов payload, HTML/PDF/relaunch,
  network sandbox (NetworkService в AppContainer/Low), удаление, сохранение
  данных, неизменность UserChoice и основной регистрации.
- На runtime alpha.9 (прямой запуск): MP4/WebM, AAC PCM, загрузки и мини-панель
  загрузок, cookies, fullscreen, внешние протоколы (19 случаев).
- Запуск и память против alpha.8 (7 прогонов, медианы): 348 → 318 мс до
  JS-callback, private 184 → 180 МиБ, CPU простоя 0,02 % — в пределах разброса,
  регресса нет.

## Известные ограничения

- Один не воспроизведённый вылет при смене темы Windows (сообщение владельца);
  причина неизвестна, отладка дочерних процессов не проводилась.
- Первый запуск после загрузки Windows с жёсткого диска может занимать 8–16 с;
  с NVMe около 1,1 с. Это скорость диска, а не код браузера.
- Окно просмотра сертификата имеет светлый фон.
- Installed media на установщике alpha.9 и ручные сценарии отдельно не
  проверялись; сравнительный замер — не первый кадр и не на холодном кэше.
- Не заявляется поддержка всех GPU, Windows N или DRM-сервисов.

Экспериментальная alpha. Сборка локальная, без Authenticode и без публикации.
Пакет исходных материалов — не заключение о выполнении условий распространения;
побитовая воспроизводимость чистой пересборки не заявляется.
