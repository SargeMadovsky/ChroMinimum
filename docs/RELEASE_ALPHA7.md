# ChroMinimum 0.0.1-alpha.7 — Windows x64

Дата подготовки: 2026-10-21. [GitHub prerelease опубликован](https://github.com/SargeMadovsky/ChroMinimum/releases/tag/v0.0.1-alpha.7): основной setup и SHA-256; серверные размер и SHA-256 сверены. Публикация на сайте ещё не выполнена. Исходники локальных изменений в GitHub пока не отправлены; тег указывает на базовый коммит, что явно отмечено в описании релиза.

## Файл для сайта

`dist/ChroMinimum-0.0.1-alpha.7-setup-x64.exe`

Офлайн-установщик, 158066396 байт (150,7 МиБ).
SHA-256: `1883a385c548aaf27b86711fb6c6f8d8bbea50c655b19c0ac2355537b596eb56`.
Рядом находится файл `.exe.sha256`. Тестовый setup с `-test-` в имени не
предназначен для публикации. Подписи Authenticode у установщика пока нет.

CEF: стандартный 154.0.34+g14c5a08 / Chromium 154.0.8037.98, без наших патчей
исходников Chromium. В поставку входят только разрешённые runtime-файлы,
английский fallback и выбираемый русский язык. Исходники, компилятор, PDB,
тестовые профили и сборочные инструменты в установщик не входят.

## Что изменилось

- Финальный логотип в значках приложения, окна и установщика.
- Иконки назад/вперёд/обновить/стоп; меню справа от адресной строки.
- Версии ChroMinimum и CEF в заголовке; окно «О программе» через меню.
- Сохранение и восстановление размера окна.
- Белый фон страниц, если собственный фон страницы не задан.
- Проверенные настройки запрета автоматических внешних предустановленных
  расширений, AI eligibility и серверного Autofill.

PDF, локальные HTML/HTM, регистрация Windows «Открыть с помощью», отдельный
каталог данных, sandbox и проверка сертификатов сохранены. Установщик
не назначает браузер приложением по умолчанию автоматически.

## Проверки и ограничения

Итоговая локальная приёмка прошла:

- TestInstall EN/RU: 4/8 языковых pak, регистрация HTML/HTM/PDF, повторное
  HTML → PDF, миграция seed с сохранением floor, отказ более низкому baseline
  до копирования, удаление и сохранение данных. Основная регистрация владельца
  и UserChoice не изменились. Размер установки без профиля: EN 389393778,
  RU 390599794 байт.
- HTTP/JavaScript, Enter/back/forward/reload и состояния окна; bundle не изменён.
- HTTPS, отказ недоверенного TLS до HTTP GET; NetworkService Low/AppContainer,
  renderer/storage Untrusted restricted и GPU Low restricted подтверждены токенами.
- Три 30-секундных сетевых сценария закрылись штатно. Нет наблюдавшихся
  запросов AI eligibility, серверного Autofill и Adobe CRX. ListAccounts,
  запрос времени и компонентные обновления Chromium остаются; компонентный
  download в свежих профилях не отключался.
- Искусственный ввод логина/пароля, событие submit без отправки в сеть,
  JS/HTTP cookies прошли. Белый фон по умолчанию, авторские тёмный фон и
  градиент проверены локальными страницами.
- Rustfmt, locked Cargo metadata, синтаксис Python/PowerShell и diff-check;
  повторно сверены размер/SHA всех 34 файлов payload. CEF libcef.dll совпал
  с исходным stock-хешем e3da6707…d79ae7.

Оболочка собрана Release; открытие About через настоящий пункт меню,
версия alpha.7 в заголовке, сохранение/восстановление 920×680 проверены
с отдельным тестовым профилем. Снимки собственных тестовых окон визуально
проверены: `.local/release-alpha7/about-preview.png` и browser-preview.png.

Новый bootstrap EXE отличается от прежнего закреплённого bootstrap только
иконками RT_ICON/RT_GROUP_ICON и необходимой перекладкой секции reloc после
роста ресурсов. Байты всех секций вне .rsrc, неиконные ресурсы, entry point,
архитектура и защитные флаги совпадают. Аудит:
`.local/release-alpha7/bootstrap-icon-audit.json`.
Хеш bootstrap в installer/seed-baseline.json обновлён после этого аудита;
libcef/chrome_elf и security sequence=1 сохранены. Проверки baseline не обходились.

Менеджер паролей не вырезан. Стартовый ListAccounts и некоторые другие
upstream-соединения остаются известным ограничением стандартного CEF.
Собственная сборка Chromium отложена по D031. Поддержки пользовательских
расширений в этом прототипе пока нет; полный uBlock Origin не заявляется.
Сравнительные замеры скорости alpha.7 отдельно не проводились.
Публичный канал обновлений с alpha.7 ещё не прошёл сквозную приёмку;
format=1 сохраняет привязку адаптера к полному установщику и отклоняет чужую DLL.

Основной и TestInstall setup собраны из одного payload. Тестовый setup SHA-256:
`a7195c5a179af48307ad6884d45a2148f1ac4a38de93250e488f6baaed17671c`.
Evidence: `.local/release-alpha7/validation-summary.json` и отдельные
installer/navigation/security/network/UI отчёты рядом. Подробные логи:
package.log и validation.log. Реальный установленный alpha.6 не заменялся.

Тексты/материалы для сайта следует описывать как экспериментальную Windows
x64 alpha-сборку. Установщик требует Windows 10 build 19041 или новее.
