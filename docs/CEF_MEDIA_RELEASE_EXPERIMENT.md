## Рецепт и история

Начато 2026-10-22 по согласию владельца после замеров alpha.8 preview.

Цель — проверить стоимость штатной official Release-конфигурации CEF с
H.264/AAC. Это эксперимент, а не готовый релиз и не обещание улучшения.
Предыдущая конфигурация автоматически включала instance tracer всех
raw_ptr/raw_ref; pinned `cef/tools/gn_args.py:GetConfigArgs` включает его
только в ветке non-official. `instance_tracer.h` при выключенной диагностике
возвращает размер raw_ptr к размеру обычного указателя. Сам BackupRefPtr
и GWP-ASan должны оставаться включены; скрипт проверяет эффективные GN args.

Запуск: `scripts/build-cef-media-release.ps1`, по умолчанию четыре задания.
Точные Chromium/CEF/depot_tools commits проверяются по source-build.json.
Конфигурацию формирует pinned CEF gn_args, а не набор догадок об upstream API.
Изменение: is_official_build=true, штатные зависимые настройки official,
кодеки сохранены, symbol_level=1, chrome_pgo_phase=0. PGO-профиль не скачивается.
Это ещё не полное совпадение с конфигурацией поставщика stock CEF.

Отдельный output: `C:\cm-media154\chromium\src\out\Release_Media_Official_x64`.
Прежний output и работающий preview сохраняются. Сборочные исправления
0002/0003 остаются закреплены; ListAccounts-патч не применяется.
Локальный журнал, args и состояние: `.local/media-release-20261022/`.
Начало — 12:38 +05. Ожидаемая цена: несколько часов CPU и десятки ГиБ SSD;
точные расходы ещё не измерены. При старте на C: было около 299 ГиБ свободно.
Новых служб, зависимостей приложения и изменений пользовательского профиля нет.

GN generation завершена: 35222 targets, 5028 файлов, 39,7 с. Эффективные
аргументы подтвердили: tracer=false, BackupRefPtr=true, оба GWP-ASan=true,
proprietary_codecs=true, is_debug=false, is_official_build=true, ThinLTO=true.
Компиляция запущена 12:39 +05; завершение и runtime-проверки пока не подтверждены.

В 17:02 +05 обнаружена остановка: процессов первого запуска нет, последние
записи siso около 13:48, итогового libcef.dll нет. Причина завершения не установлена;
state.json первого запуска остался устаревшим на compiling. В 17:03 сборка
возобновлена из того же output в отдельном видимом PowerShell, с использованием
накопленных результатов. Это окно выполняет саму сборку, а не только tail журнала.

отсутствуют. Последняя запись .ninja_log — 01:07:52 +05, 48673 записи выходных
файлов (не число заданий и не процент готовности); libcef.dll ещё нет. Явная
ошибка компилятора не установлена. Повторно запущен тот же рецепт в видимом
PowerShell с прежним output, без очистки промежуточных результатов.

После компиляции обязательны отдельная упаковка, MP4/WebM/AAC, fullscreen,
штатное закрытие, TLS/PDF и sandbox-токены, затем парные замеры stock / preview /
