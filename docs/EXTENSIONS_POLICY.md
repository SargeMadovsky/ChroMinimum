# Политика расширений

Статус: требования к будущему продукту. Реализованной поддержки пока нет.

## Обязательства проекта

- Совместимость с распространёнными WebExtensions приоритетнее собственного формата.
- Цель — MV2 и MV3 с динамической блокировкой/изменением запросов, а также декларативными правилами.
- Установка из файлов и каталогов без обязательного магазина и аккаунта браузера.
- Новые версии API не удаляют полезные возможности ради коммерческих интересов.
- Разрешения защищают выбор пользователя; широкие права допускаются с явным информированием и возможностью отзыва.
- Уязвимости исправляются; совместимость не требует сохранения опасного поведения. Несовместимые изменения документируются с альтернативами, где возможно.

## Матрица целевой совместимости

| Область | Цель | Состояние |
|---|---|---|
| Manifest | MV2 и MV3 | Не проверено |
| Сеть | webRequest и blocking, declarativeNetRequest | Не проверено |
| Страницы | Content scripts, CSS, изолированные контексты, user scripts | Не проверено |
| Фон | Background pages и service workers согласно manifest | Не проверено |
| API | runtime, messaging, storage, tabs, windows, permissions | Не проверено |
| UI | Action popup, options, context menus | Не проверено |
| Firefox-специфика | Совместимость по отдельным API, без обещания полной эмуляции | Не проверено |
| Native messaging | Отдельное исследование и модель доверия | Отложено |

Каждый API получает тест и запись поддерживаемых ограничений. Совместимость с каталогом магазина не означает автоматическое право на распространение его пакетов.

## Контрольные расширения

uBlock Origin: MV2, сетевые правила, косметическая фильтрация, scriptlets, UI и хранение настроек. Tampermonkey: установка и запуск скриптов, URL matching, разрешения и хранилище. Далее Dark Reader и Bitwarden: DOM/CSS, сообщения, формы и жизненный цикл.

Фиксировать конкретную версию и вариант расширения. Проверка Chrome-пакета не доказывает совместимость Firefox-пакета. uBlock Origin Lite не является заменой полной версии в приёмке.

## Жизненный цикл и контроль

Установка → просмотр источника/прав → согласие пользователя → запуск. Обновление с новыми правами требует согласия. Отключение отменяет подписки и работу расширения; отзыв host permissions действует на существующие страницы по документированной модели. Удаление предлагает понятную политику удаления данных.

Конфликты блокировщиков, задержки обработчиков, сбои и лимиты ресурсов должны быть наблюдаемыми и проверяемыми. Не отключать фильтрацию незаметно при ошибке. Не вводить рекламные исключения без выбора пользователя.
