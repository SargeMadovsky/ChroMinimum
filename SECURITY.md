# Security

ChroMinimum is an experimental prototype. Independent security review and a
production security-update policy are not yet complete.

Please report vulnerabilities privately using **Security → Report a vulnerability**
in [this repository](https://github.com/SargeMadovsky/ChroMinimum/security).
Private vulnerability reporting is enabled. Please avoid posting exploits,
credentials or private browsing data in public issues.

Do not disable Chromium sandboxing, certificate validation or site isolation to
work around a bug. Include the release version, platform and a minimal test case.
